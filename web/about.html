ℹ️ About ClimateGuard

AI-Powered Heatwave Prediction System for Indian Cities

🎯 Project Overview

ClimateGuard is a machine learning system that predicts heatwave events one day in advance for 5 major Indian cities. It combines a Random Forest classifier trained on 35 years of ERA5 climate data with a deterministic expert rule engine inspired by India Meteorological Department (IMD) heatwave definitions.

The system provides not just binary predictions, but also risk levels, expert rule assessments, and actionable adaptation recommendations to help communities prepare for extreme heat events.

🏗️ System Architecture

1

Data Ingestion

ERA5 Reanalysis data from ECMWF covering 1990–2025. Includes temperature, humidity, wind, pressure, geopotential, and radiation variables across surface and pressure levels.

→
2

Feature Engineering

110 features including rolling means (3, 5, 7, 14-day), rate of change, z-scores, departures from climatological normals, cross-variable interactions, and seasonal indicators.

→
3

ML Prediction

Random Forest Classifier with random undersampling for class imbalance. Threshold tuned to 0.70 for optimal F1 balance. Temporal train/test split avoids data leakage.

→
4

Risk Engine

Converts probability to risk levels (LOW / MODERATE / HIGH / EXTREME) with adaptation recommendations tailored to each level.

→
5

Expert Rules

7 IMD-inspired deterministic rules that overlay on ML predictions: Extreme Temperature, Persistent Heat, High Nighttime Temperature, Compounded Heat Stress, Vulnerable Population Alert, Outdoor Exposure Warning, Hydration Reminder.

🌡️ Heatwave Definition

This project uses an IMD-inspired heatwave definition applied to ERA5 reanalysis grid data:

Region Type Heatwave Threshold Severe Heatwave
Plains Tmax ≥ 40°C or departure ≥ 4.5°C Tmax ≥ 45°C or departure ≥ 6.5°C
Coastal Tmax ≥ 37°C or departure ≥ 4.5°C Tmax ≥ 41°C or departure ≥ 6.5°C

⚠️ These thresholds are applied to ERA5 model output, not official IMD station observations. ERA5 grid-cell values may differ from ground-station readings.

⚠️ Disclaimer

This is a student research project. The predictions and risk assessments are generated by a machine learning model trained on reanalysis data and are NOT official government forecasts or certified medical advice.

  • Predictions use ERA5 reanalysis data, not official IMD station observations.
  • Risk levels and adaptation recommendations are project-defined.
  • Always follow instructions from local meteorological authorities during heat emergencies.
  • Do not use this system as the sole basis for emergency planning decisions.
