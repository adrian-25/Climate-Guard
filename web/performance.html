Model performance

Evaluation on the held-out temporal test set (2023–2025) across five Indian cities.

Europe-v1 uses a relative, non-official research heatwave definition (≥3 consecutive warm-season days above the city-specific 90th percentile and 30°C floor; baseline 1991–2020). Metrics are not comparable to the India model or to official national weather-service criteria.

Recall and precision are the most important metrics for an early-warning system. High recall means fewer missed heatwave days (false negatives); high precision means fewer false alarms. This model is tuned for recall—it catches most heatwave days at the cost of some false alarms.

Deep learning comparison (research)

GRU and LSTM sequence models trained on the same India training window (1990–2019) and evaluated on the same held-out test set. This is a research comparison only—ClimateGuard uses the Random Forest model in production.

All bootstrap confidence intervals for the F1 difference (DL minus RF) include zero. Results are described as competitive with no statistically significant difference.
